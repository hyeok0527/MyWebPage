## 1. 수행 기간과 진행 상태

- 수행 기간: 10월 31일 ~ 현재
- 진행 상태: 주요 화면 구현 및 배포 후 콘텐츠 보완 중
- 사용 기술: Hugo, Blowfish, Git, GitHub Actions, GitHub Pages

## 2. 프로젝트 목적

자기소개와 프로젝트, 학습 경험을 한곳에서 확인할 수 있는
개인 포트폴리오 사이트를 만드는 것이 목표였습니다.

Blowfish 테마의 아이콘과 은은한 색상이 마음에 들어 선택했습니다.
테마의 기본 디자인은 유지하면서, 개인 소개에 필요한 정보가
명확하게 보이도록 화면을 구성하고자 했습니다.

## 3. 본인 역할과 AI 활용

개인 프로젝트로 저장소 생성, 파일 적용, 콘텐츠 작성,
커밋 및 배포 결과 확인을 수행했습니다.

레이아웃과 상호작용 코드의 초안 작성에는 AI의 도움을 받았습니다.
제안받은 파일을 저장소에 적용하고, 배포 과정에서 발생한 오류를
확인하며 누락 파일과 참조 경로를 수정했습니다.

## 4. 수행 과정과 선택 이유

### 포트폴리오에 맞게 테마 정리

후원자 목록, 테마 미리보기, 후원 링크, 불필요한 외부 링크 등
개인 소개와 직접 관련이 없는 요소를 제거했습니다.

기본 배경은 유지하고, 자기소개와 프로젝트로 연결되는 정보를
중심으로 메뉴와 홈 화면을 재구성했습니다.

### GitHub Actions를 활용한 배포

GitHub에 새 저장소를 만들고 파일을 업로드한 뒤,
GitHub Actions와 GitHub Pages를 활용해 사이트를 배포했습니다.

수정 내용을 커밋하고 push한 후에는 Actions의 실행 결과를 확인했습니다.
빌드가 실패하면 오류를 수정하고 새 커밋으로 재배포했습니다.

### 파일 누락과 이미지 경로 문제 해결

AI가 작성한 수정 파일을 옮기는 과정에서 기존 파일 일부가 누락되어
배포에 실패했습니다.

오류 로그를 통해 테마 파일을 찾지 못하는 상황을 확인하고,
이전 커밋에서 필요한 테마 폴더를 복구했습니다.
배경 이미지처럼 필요한 파일도 원본에서 다시 가져왔습니다.

이미지 참조 경로가 실제 파일 위치와 일치하지 않는 경우에는
경로를 수정하여 임시 이미지를 불러왔습니다.

### 홈 화면의 정보 구조 개선

줄글 중심의 홈 화면을 다음 세 영역으로 나누었습니다.

1. 프로필 사진과 자기소개
2. 관심 분야
3. 자기소개·프로젝트·GitHub 바로가기

텍스트 링크는 카드 형태로 변경해 클릭 가능한 영역을 구분하기 쉽게 했습니다.
스크롤 등장 효과와 카드 강조 효과도 추가하여 화면의 흐름을 개선했습니다.

## 6. 배운 점과 개선 방향

파일을 수정하고 push하는 것과 실제 배포가 성공하는 것은
별도로 확인해야 한다는 점을 배웠습니다.

또한 부분 수정 파일을 적용할 때 기존 폴더 전체를 대치하면
필수 파일이 누락될 수 있으므로, 변경할 파일을 구분하고
Git으로 변경 내용을 확인하는 것이 중요하다는 점을 알게 되었습니다.

앞으로 모바일 화면, 키보드 이동, 링크와 이미지 경로를 점검하고,
프로젝트 설명과 검증 기록을 보완할 계획입니다.
