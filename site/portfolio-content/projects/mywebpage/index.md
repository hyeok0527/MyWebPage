- 수행 기간: [직접 입력: 실제 시작일 ~ 현재 또는 완료일]
- 현재 상태: 진행 중 — 소개·프로젝트 콘텐츠와 검증 기록을 보완하고 있습니다.

## 2. 프로젝트 목적

자기소개와 학습 활동을 한곳에 정리하고, 로그인 없이 확인할 수 있는 포트폴리오 사이트를 만드는 것이 목표입니다.
결과물뿐 아니라 수정 과정과 문제 해결 경험도 기록하고자 합니다.

## 3. 본인 역할과 기여 범위

개인 포트폴리오로 진행했습니다. 소개 문구와 콘텐츠를 작성하고, 테마 설정을 수정하여 GitHub에 반영한 뒤 공개 배포 화면을 확인했습니다.

기본 화면과 기능은 Blowfish 테마를 활용했습니다. 사이트 준비에는 수업 제공 스크립트를 사용했고, 수정 방향과 오류 점검에는 AI의 도움을 받았습니다.

[직접 입력: 실제로 직접 수행한 범위를 확인하고, 하지 않은 작업은 삭제하세요. 추가로 수정한 파일이나 맡은 작업이 있다면 적으세요.]

## 4. 수행 과정과 선택 이유

1. Blowfish 테마와 수업 제공 스크립트로 사이트 구조와 배포 구성을 준비했습니다.
2. 홈 소개와 자기소개 페이지를 작성하고 테마 설정을 수정했습니다.
3. 변경 내용을 commit·push하고 공개 배포 결과를 확인했습니다.
4. 수정 사항이 반영되지 않는 문제를 점검하고 자기소개 문서를 다시 작성했습니다.
5. 예제 메뉴와 홈의 테마 데모 영역을 개인 포트폴리오 구성으로 정리하고 있습니다.

**선택 이유**: [직접 입력: Hugo·Blowfish·GitHub Pages 중 한 가지를 선택한 실제 이유. 예: Markdown 작성 방식, 원하는 디자인, 수업에서 배운 배포 방식 등.]

### 문제 해결: 수정 후에도 이전 화면이 남음

- 관찰: 수정 후 push했지만 공개 사이트에 이전 화면이 남았습니다.
- 점검과 조치: 자기소개 문서의 경로를 점검하고 문서를 다시 작성했습니다.
- 결과: 다시 배포한 뒤 변경된 홈페이지가 표시되는 것을 확인했습니다.
- 확인 범위: 정확한 실패 원인은 당시 Actions 로그와 함께 확인해야 하며, 문서 추가 전후의 관찰 결과와 원인 확정은 구분합니다.

[직접 입력: 해당 수정 커밋과 Actions 실행 링크. 로그에서 확인한 오류가 있다면 실제 문구도 추가하세요.]
