## 2. 활동 목적

초급프로젝트 실습에서 배운 내용을 바탕으로,
외부 API에서 제공하는 데이터를 웹페이지와 연결하는 과정을
경험하고자 했습니다.

## 3. 본인 역할

교수님이 제공한 파일을 기반으로 실습을 진행했습니다.
제공 코드 전체를 직접 개발한 것은 아니며,
API 연결을 설정하고 실제 TMDB와 연동되는지 확인했습니다.

- 직접 설정하거나 수정한 파일: [직접 입력: 파일 경로와 수정 내용]

## 4. 수행 과정

제공된 프로젝트 구조와 API 연결 부분을 살펴보고,
실습 안내에 따라 TMDB API를 연결했습니다.

이후 웹페이지를 실행하여 API에서 전달받은 데이터가
화면에 표시되는지 확인했습니다.

- [직접 입력: 연결 과정에서 어려웠던 점이나 확인 방법]

## 6. 배운 점과 개선 방향

외부 서비스의 데이터를 웹페이지에서 활용하려면
API 요청과 응답을 연결하는 과정이 필요하다는 점을 배웠습니다.

앞으로 제공 코드의 데이터 요청 흐름을 더 자세히 분석하고,
로딩 상태와 오류 처리 방식도 이해하고자 합니다.
