## 1. 수행 기간과 진행 상태

- 진행 상태: 지속적으로 학습 중
- 사용 언어: Python

## 2. 학습 목적

개인 코딩 역량을 강화하기 위해 백준 문제를 풀고,
자료구조 수업에서 배운 정렬 알고리즘을 Python으로 구현했습니다.

Python은 인공지능 분야에서도 널리 활용되는 언어이므로,
알고리즘 학습과 함께 언어 사용 능력을 높이고자 선택했습니다.

## 3. 직접 수행한 작업

백준 문제의 풀이 코드를 작성하고,
수업에서 배운 자료구조를 직접 구현해 보았습니다.

- 대표 문제: homework 6_1_3 hash table
- 구현한 자료구조: 수업 과제에서 나온 문제로서 hash table을 구현하였습니다.
- 관련 코드: (https://github.com/hyeok0527/practice_python/blob/main/homework_6_1_3.py)

## 4. 어려웠던 점과 개선 과정

문제 풀이 과정에서 시간 초과(TLE)가 자주 발생했습니다.
답을 계산하는 방법뿐 아니라 입력 크기에 적합한 알고리즘과
자료구조를 선택해야 한다는 점을 느꼈습니다.

시간 초과가 발생했을 때는 정렬 방식과 반복 처리 과정을 살펴보고,
더 적합한 풀이 방법을 찾으려고 노력했습니다.

## 6. 배운 점과 다음 계획

문법을 알고 코드를 작성하는 것만으로는 충분하지 않으며,
입력 크기와 시간 복잡도를 고려해야 한다는 점을 배웠습니다.

앞으로 시간 초과가 발생한 문제를 다시 분석하고,
알고리즘과 자료구조의 선택에 따라 처리 과정이 어떻게 달라지는지
비교하며 학습할 계획입니다.
